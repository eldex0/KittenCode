# KittenCode Portfolio

A bilingual portfolio for the open-source projects published by
[`eldex0`](https://github.com/eldex0). The project list is loaded automatically
from the public GitHub API.

## Deployment

This is a static website. On Cloudflare Pages, use:

- Production branch: `main`
- Build command: none
- Build output directory: `dist`
